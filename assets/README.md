# CodexQuota icon

`CodexQuota.png` is the original generated transparent RGBA artwork: a blue outer quota arc and a silver inner quota arc, with no lettering.

`CodexQuota.ico` contains the same image resized to 16, 20, 24, 32, 48, 64, 128, and 256 pixels using Pillow's ICO exporter. The application uses it for its executable, notification area, and settings window.

The base64 transfer intermediate is excluded from releases under `artifacts/`.
